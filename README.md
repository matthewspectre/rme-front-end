# Rekam Medis Elektronik (RME) – Frontend

Frontend untuk Sistem Rekam Medis Elektronik (RME) yang menyediakan antarmuka pengguna untuk mengelola dan menampilkan data layanan kesehatan. Aplikasi ini terhubung dengan REST API backend untuk melakukan pengambilan, pengiriman, dan pengelolaan data secara terintegrasi.

## 🚀 Fitur

- Menampilkan ringkasan informasi layanan kesehatan
- Menampilkan informasi dan data secara terstruktur
- Manajemen Data Pasien
- Menampilkan riwayat rekam medis pasien
- Menghubungkan frontend dengan backend melalui REST API
- Navigasi antar halaman
